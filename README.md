# Yonderia

Next.js 16 App Router project scaffold for the Yonderia group vacation planner.

## Setup

1. Copy .env.local.example to .env.local and fill in the Supabase and Google API keys.
2. Install dependencies with npm install.
3. Start the app with npm run dev.

## Scripts

- npm run dev starts Next.js with Turbopack.
- npm run lint runs ESLint.
- npm run build creates a production build.
- npm run start runs the production server.
